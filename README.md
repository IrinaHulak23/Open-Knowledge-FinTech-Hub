# Open-Knowledge-FinTech-Hub
Open Knowledge FinTech Hub — це відкритий освітньо-науковий ресурс, створений з метою популяризації сучасних досліджень у сфері фінансових технологій (FinTech). У межах хабу зібрано структуровані огляди та аналітичні описи наукових статей провідних світових учених, опублікованих переважно протягом останніх років.
Багато високоякісних наукових публікацій залишаються малодоступними для широкої аудиторії через платний доступ до журналів або складність академічного викладу. Open Knowledge FinTech Hub покликаний зробити результати сучасних досліджень більш доступними для студентів, викладачів, дослідників, представників фінансового сектору та всіх, хто цікавиться розвитком фінансових технологій. Ресурс дає можливість ознайомитися з актуальними напрямами досліджень, методологічними підходами, основними висновками та перспективами розвитку FinTech у провідних університетах і наукових центрах світу.
Особливістю хабу є те, що всі оригінальні наукові статті представлені англійською мовою, тоді як їхні структуровані огляди та аналітичні описи підготовлені українською. Це робить результати сучасних міжнародних досліджень значно доступнішими для українських студентів, викладачів, практиків і всіх, хто прагне зрозуміти новітні тенденції розвитку фінансових технологій без необхідності детального опрацювання англомовних академічних текстів.
Хаб також є освітньою платформою, що сприяє розвитку навичок академічного аналізу, критичного мислення та роботи з сучасною науковою літературою. Підготовка оглядів здійснювалася студентами в межах навчального процесу під науковим керівництвом викладача.
