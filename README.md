# Open-Knowledge-FinTech-Hub
Open Knowledge FinTech Hub — це відкритий освітньо-науковий ресурс, створений з метою популяризації сучасних досліджень у сфері фінансових технологій (FinTech). У межах хабу зібрано структуровані огляди та аналітичні описи наукових статей провідних світових учених, опублікованих переважно протягом останніх років.
